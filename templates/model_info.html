Neural Network Model

Detailed Information About Our Weather Prediction System

Model Overview

Architecture

3-Layer Feedforward Neural Network

  • Input Layer: 10 weather parameters
  • Hidden Layer 1: 5 neurons with Sigmoid activation
  • Hidden Layer 2: 5 neurons with Sigmoid activation
  • Output Layer: 1 neuron with Sigmoid activation
Training Details

Model trained on Cambodia weather data (2022-2024)

  • Loss Function: Binary Cross Entropy
  • Optimizer: Stochastic Gradient Descent (SGD)
  • Activation: Sigmoid functions
  • Framework: PyTorch

Input Features (10 Parameters)

Temperature & Humidity
Temperature (°C) Range: -20°C to 50°C
Feels Like Maximum (°C) Range: -20°C to 60°C
Dew Point (°C) Range: -30°C to 40°C
Humidity (%) Range: 0% to 100%
Cloud Cover (%) Range: 0% to 100%
Pressure & Wind
Sea Level Pressure (inHg) Range: 28 to 32 inHg
Wind Speed (mph) Range: 0 to 100 mph
Wind Direction (degrees) Range: 0° to 360°
Wind Gust (mph) Range: 0 to 150 mph
Visibility (miles) Range: 0 to 50 miles

Model Performance & Output

Prediction Output

Binary classification: Rain Expected / No Rain Expected

Based on probability threshold of 0.5
Probability Score

Confidence level from 0% to 100%

Higher values indicate greater certainty
Recommendations

Weather-based activity suggestions

Tailored to probability levels

Technical Implementation

Data Processing
  • Normalization: Z-score standardization using training statistics
  • Input Validation: Range checking for all parameters
  • Missing Values: Not allowed - all fields required
  • Data Storage: SQLite database for predictions history
Backend Technology
  • Framework: Django REST Framework
  • Model Loading: Joblib serialization
  • API Endpoints: RESTful JSON API
  • Real-time Processing: On-demand predictions
